## 🧠 AI Resume Analyzer & Builder  
🔗 [Live Demo](#) • 🔗 [GitHub](#)  
**Stack**: React, Node.js, LangChain, Gemini AI, PDF.js

**Overview**  
An AI-powered web tool that allows users to upload resumes and receive basic ATS feedback.

**Key Features**
- Parses uploaded PDF resumes using PDF.js
- Generates an ATS score using Gemini and LangChain prompts
- Provides basic suggestions to improve resume content
- Enables resume export after suggestions

**Challenges**
- Integrated PDF.js to read and extract text content
- Designed prompt flow for scoring and suggestions

**Outcome**
- Gained hands-on experience combining AI APIs with PDF input
- Learned prompt formatting and chaining in LangChain

## 📝 AI Blog URL to Social Media Post Generator  
🔗 [Live Demo](#) • 🔗 [GitHub](#)  
**Stack**: Express.js, LangChain, Gemini AI

**Overview**  
A tool that converts blog articles into short-form social media content using LLMs.

**Key Features**
- Accepts blog URL and fetches content
- Summarizes the blog and generates posts
- Supports tone customization and target audience selection
- Offers real-time post editing

**Challenges**
- Designed prompts for summarizing long-form content into short copy
- Focused on AI workflow over frontend polish

**Outcome**
- Explored prompt engineering and sequential content generation with LangChain
- Learned to balance output relevance with input variability
